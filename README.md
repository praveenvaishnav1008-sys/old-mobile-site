# Old Mobile Sell Website

This is a simple static website to list and browse used mobile phones for sale.

## How to Run

1.  Clone or download this repository.
2.  Navigate to the project directory.
3.  Open the `index.html` file in your web browser (e.g., Chrome, Firefox, Safari).

That's it! You should see the website with a list of mobile phones. You can use the search bar to filter the phones by model.
